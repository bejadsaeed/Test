# يا تلحق يا متلحقش 🔨

تطبيق ألعاب لمّة على موبايل واحد، شغال أوفلاين بالكامل. فيه 3 ألعاب:

| اللعبة | الفكرة | اللاعيبة |
|---|---|---|
| 🔨 **المزاد** | زايد على عدد الإجابات اللي تقدر تقولها والحق قبل الوقت. نجاح = 100 × المزايدة، فشل = −500، و«الواسطة» حدث دهبي نادر ×2 | 2–12 |
| 💣 **القنبلة** | كل واحد يقول إجابة ويسلّم الدور؛ اللي القنبلة تفرقع في دوره يخسر الجولة. وقت ثابت أو عشوائي، 3 أجواء صوت (عادي / توتر / سينمائي) | 2–12 |
| 🏘️ **أهل القرية** | 1–3 حرامية مستخبيين؛ توزيع أدوار سري، نقاش، تصويت سري، والمطرود دوره يفضل سر لحد النهاية | 3–12 |

- 594 سؤال في 8 فئات (مشتركة بين المزاد والقنبلة)، مع تجنّب أسئلة آخر 3 ماتشات لكل لعبة.
- نظام صوت موحّد: Master / Music / SFX، كتم سريع، والإعدادات بتتحفظ على الجهاز. كل الأصوات ملفات محلية في `src/audio/`.

## iPhone / الويب (PWA)

نفس الكود بيطلع منه نسخة ويب في `web/` (ناتج `python3 build.py`): ملف واحد فيه الكود والخطوط والأصوات + `sw.js` + `manifest`.
على Safari: زر المشاركة ← «إضافة إلى الشاشة الرئيسية». بعد أول فتحة بتشتغل من غير نت (Service Worker)، وبيانات اللاعيبة والإعدادات ليها نسخة احتياطية في IndexedDB.

## الملفات

| المسار | الوصف |
|---|---|
| `src/app.js` | النواة المشتركة (لاعيبة، تنقّل، واجهة، تسجيل الألعاب `YTM.register`) + لعبة المزاد |
| `src/bomb.js` · `src/village.js` | لعبة القنبلة ولعبة أهل القرية — كل لعبة في ملف مستقل |
| `src/audio.js` · `src/audio/` | نظام الصوت الموحد (AudioSys) وملفات الصوت المحلية (mp3) |
| `src/questions.js` · `src/styles.css` | قاعدة الأسئلة ونظام التصميم |
| `tools/gen_audio.py` | مولّد ملفات الصوت (تخليق كامل، من غير أي عينات خارجية) |
| `build.py` | يبني `dist/web` (PWA) و `dist/single/index.html` (ملف واحد للـ APK) |
| `android/` | مشروع Android (WebView بيحمّل اللعبة من الـ assets) — يتفتح في Android Studio / Gradle |
| `build-apk.sh` | بناء وتوقيع الـ APK من غير Gradle |
| `tests/e2e.py` · `tests/e2e_games.py` | اختبارات آلية بتلعب ماتشات كاملة للألعاب التلاتة على متصفح بمقاس موبايل |
| `release/yatelha2.apk` | آخر APK موقّع |

## البناء

```bash
python3 build.py                     # web + single-file
python3 tests/e2e.py "$PWD"          # المزاد: 33 فحص (محتاج playwright)
python3 tests/e2e_games.py "$PWD"    # القنبلة + أهل القرية + الصوت: 76 فحص
python3 tests/e2e_ios.py "$PWD"      # نسخة الـ PWA ببروفايل iPhone: 25 فحص
SDK=/path/to/tools ./build-apk.sh    # APK → dist/apk/yatelha2.apk
```

مفتاح التوقيع (`android/keystore/yatelha2.jks`) مش مرفوع على الريبو عن قصد؛ احتفظ بنسختك منه عشان التحديثات تتثبت فوق النسخة القديمة.

معرّف التطبيق: `com.bgz.yatelha2` — Android 6.0 (API 23) وأحدث.
