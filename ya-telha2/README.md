# يا تلحق يا متلحقش 🔨

لعبة لمّة على موبايل واحد (2–12 لاعب). أول لعبة: **المزاد** — زايد على عدد الإجابات اللي تقدر تقولها، والحق قبل الوقت ما يخلص.

- **نجاح:** 100 نقطة × المزايدة — **فشل:** −500
- **الواسطة:** حدث دهبي نادر (5%، مرة واحدة بحد أقصى في الماتش) بيضاعف المكسب والخسارة ×2، وبيظهر بعد قفل المزاد.
- 594 سؤال في 8 فئات، من غير تكرار جوه الماتش، مع تجنّب أسئلة آخر 3 ماتشات.
- بتشتغل أوفلاين بالكامل (خطوط وأصوات وأسئلة جوه التطبيق).

## الملفات

| المسار | الوصف |
|---|---|
| `src/` | كود اللعبة: `app.js`، `styles.css`، `questions.js` (قاعدة الأسئلة)، الخطوط والأيقونة |
| `build.py` | يبني `dist/web` (PWA) و `dist/single/index.html` (ملف واحد للـ APK) |
| `android/` | مشروع Android (WebView بيحمّل اللعبة من الـ assets) — يتفتح في Android Studio / Gradle |
| `build-apk.sh` | بناء وتوقيع الـ APK من غير Gradle |
| `tests/e2e.py` | اختبار آلي بيلعب ماتشات كاملة على متصفح بمقاس موبايل |
| `release/yatelha2.apk` | آخر APK موقّع |

## البناء

```bash
python3 build.py                     # web + single-file
python3 tests/e2e.py "$PWD"          # 33 فحص (محتاج playwright)
SDK=/path/to/tools ./build-apk.sh    # APK → dist/apk/yatelha2.apk
```

مفتاح التوقيع (`android/keystore/yatelha2.jks`) مش مرفوع على الريبو عن قصد؛ احتفظ بنسختك منه عشان التحديثات تتثبت فوق النسخة القديمة.

معرّف التطبيق: `com.bgz.yatelha2` — Android 6.0 (API 23) وأحدث.
